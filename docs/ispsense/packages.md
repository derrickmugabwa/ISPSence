## Create an offer

Open Billing → Packages and create a package. Set a recognizable name, price, duration, download and upload limits, and the supported service types: Hotspot, PPPoE, or both.

An optional data allowance is a hard access-period cap. Leave it empty for unlimited data. Fair usage policies are configured separately and can reduce speed after thresholds; see [FUP](/docs/fup).

## Understand saved terms

Purchases preserve a snapshot of their package terms. Editing today's package does not silently rewrite a customer's existing purchase. Disable an offer when you no longer want it used for new purchases; retain the history needed to explain old transactions.

The editor displays Mbps and decimal GB. The backend stores speed in bits per second, allowance in bytes, and money in minor currency units. Calendar-month durations are distinct from a fixed number of days.

## Check eligibility

Choose a package that supports the customer's service type. Captive portals list eligible Hotspot offers; PPPoE funding requires PPPoE-compatible terms.

## Expected result

The offer appears in the package directory and is available to eligible workflows. Saving a package does not collect money or configure a router. Continue with [customers](/docs/customers) or [payments](/docs/payments).
