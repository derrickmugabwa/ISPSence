## Review network changes

Network configuration changes can interrupt management or subscriber connectivity. Review the target device, requested difference, and available validation before applying a change.

## Settings

Settings includes the application's change-guard options for supported network operations. Read the controls shown in your installation before relaxing validation. A generic guard setting does not qualify customer billing activation or bypass the provisioning protocol.

Keep a recoverable device configuration and a management recovery path for consequential network changes. See [Backups](/docs/backups) and [Provisioning](/docs/provisioning).
